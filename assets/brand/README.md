# ブランド素材の置き場

ロゴなどの素材をこのフォルダにそのまま入れてください。
中を見て、ページに合うものをこちらで選んで組み込みます。

ファイル名は変えなくて大丈夫です。整理もしなくて大丈夫です。

## 入れてもらえると嬉しいもの

- ロゴ（`.svg` があれば最優先。無ければ `.png`）
- シンボルだけのもの / 「KNCT UNIVERSITY」の文字が入ったもの、両方あれば両方
- 白背景用（濃い色のロゴ）と、濃い背景用（白抜きのロゴ）、両方あれば両方
- 使っている写真があればそれも

## 使い道

| 置き場所 | 背景 | 必要なロゴ |
|---|---|---|
| ページ左上のヘッダー（高さ40px程度） | 白 | 濃い色 |
| OGP画像（LINEのリンクプレビュー） | ダークティール `#00353B` | 白抜き |
| favicon | ダークティール | 白抜き・シンボルのみ |

## 注意

`.psd` や `.ai` は無くて構いません（1ファイル100MBを超えるとGitHubが受け付けません）。
書き出し済みの `.svg` / `.png` / `.jpg` があれば十分です。
