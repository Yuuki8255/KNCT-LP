# KNCT UNIVERSITY — 面談予約完了ページ

LINE のステップ配信から、**面談を予約した直後の人**に送るページです。
面談前に見てもらって「準備してから来てもらう」ことで、無断キャンセルを減らし、
当日の会話の質を上げる目的で作っています。

参考にした構成：確認 → 事前動画 → 当日の流れ → 実績 → 直前のリマインド

---

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | ページ本体（文章はここを直接書き換えます） |
| `styles.css` | 見た目。色は先頭の `:root` にまとまっています |
| `script.js` | 動画の埋め込みと、カレンダー追加ボタン |
| `api/ics.js` | `.ics` ファイルを返すだけの小さな関数（下記参照） |
| `assets/og.png` | LINEでURLを送った時のプレビュー画像 |
| `vercel.json` | noindex・セキュリティヘッダ |

ビルド不要です。Vercel に置くだけで動きます。

> `api/ics.js` だけはサーバーが要るので、`index.html` をローカルのファイルとして
> 直接開いた場合、`.ics` ボタンだけ動きません。他は全部そのまま動きます。

## 1. 動画を入れる

`script.js` の先頭、`VIDEO_URL` に URL を貼るだけです。

```js
VIDEO_URL: "https://www.youtube.com/watch?v=xxxxxxxxxxx",
```

- YouTube（`watch?v=` / `youtu.be` / `shorts` / `live`）
- Vimeo
- `.mp4` などの直リンク

に対応しています。空のままだとプレースホルダーが表示されます。

> YouTube に上げる場合は「限定公開（Unlisted）」がおすすめです。
> 検索には出ませんが、URL を知っている人は見られます。

現在は `assets/video/call-confirmed.mp4` を直リンクで使っています
（元は 4K・234MB・HEVC だったものを、720p・H.264・約18MBに変換したもの）。
`VIDEO_POSTER`（`assets/video-poster.webp`）は読み込み中に出るサムネイルです。
動画を差し替える時は、同じファイル名に上書きするか、`VIDEO_URL` / `VIDEO_POSTER`
のパスを変えてください。

## 2. カレンダー追加ボタン（一人ひとり別の日時）

このセクションは **URL に面談日時が渡された時だけ表示されます。**
日時が無ければセクションごと出ないので、全員に同じ「日時の入っていないボタン」を
見せてしまうことはありません。

LINE のステップ配信やフォーム側で、予約日時を URL の後ろに付けて送ってください。

```
https://example.com/?start=2026-09-20T14:00
https://example.com/?start=2026-09-20T14:00&name=山田&dur=45
```

### 使えるパラメータ

| パラメータ | 内容 | 例 |
|---|---|---|
| `start` | 面談の開始日時（**必須**）。他に `datetime` `date` `d` `t` も可 | `2026-09-20T14:00` |
| `end` | 終了日時（任意） | `2026-09-20T14:45` |
| `dur` | 所要時間・分（任意。`end` が無い時に使う） | `45` |
| `name` | 相手の名前（任意。「◯◯ 様」と表示されます） | `山田` |

- タイムゾーンを書かない場合は**日本時間**として扱います。
- `end` も `dur` も無い場合は `script.js` の `DEFAULT_DURATION_MIN`（初期値 45分）を使います。
  実際の面談時間に合わせて変えてください。
- UNIX 時間（秒 / ミリ秒）や `2026-09-20T14:00+09:00` のような形式もそのまま渡せます。

日本語の名前を渡す時は URL エンコードしてください（多くの配信ツールは自動でやってくれます）。

### ボタンの中身

- **Google カレンダー** … Google の追加画面が開きます
- **Apple / その他（.ics）** … `.ics` ファイルをその場で生成してダウンロードします
- **Outlook** … Outlook の追加画面が開きます

`.ics` はブラウザ内で作らず、`api/ics.js` が本物のファイルとして返しています。
ブラウザ内で作る方式（blob）だと、**LINEのアプリ内ブラウザでは保存が始まらない**ためです。

予定のタイトル・説明・場所を変えるときは、**2ファイル両方**を直してください。

- `script.js` の `CONFIG` … Google / Outlook のボタン用
- `api/ics.js` の `EVENT` … `.ics` ファイル用

## 3. デザインと色

**一番上（ロゴ・見出し・動画）は joinknct.com と同じ黒、そこから下は白。アクセントはティファニーブルーです。**
値は `styles.css` 先頭の `:root` にまとまっているので、そこだけ触れば全体が変わります。
黒い面（ヒーロー・フッター）は、同じ変数を `.hero, .site-foot` で上書きしているだけなので、パーツは共通です。

| 変数 | 値 | 使い所 |
|---|---|---|
| `--bg` / `--bg-alt` | `#FFFFFF` / `#F6F4EF` | 地。セクションごとに交互に敷いて、話の区切りを見せる |
| `--surface` | `#FFFFFF` | カード |
| `--line` | `#E5E1D7` | カードの枠・罫 |
| `--heading` | `#111315` | 見出し |
| `--text` | `#33373D` | 本文（白地で 12:1） |
| `--muted` | `#62666D` | 補足（白地で 5.8:1） |
| `--tiffany` | `#81D8D0` | ティファニーブルー。バッジ・番号・チェックの塗り |
| `--tiffany-mid` | `#17A29B` | 実績の大きい数字 |
| `--tiffany-deep` | `#0B7A75` | 見出しの強調・小さいラベル文字（白地で 5.2:1） |
| `--tiffany-tint` | `#E7F6F4` | ラベルの薄い下地 |
| `--cream` | `#ECE7D3` | ブランドカラー。ロゴと同じ色（黒い面で使う） |

`#81D8D0` そのものは白地だと 1.6:1 しか差がなく読めないので、文字には使わず「塗り」にだけ使っています。
文字をティファニーにしたい時は `--tiffany-deep` を使ってください。

動画は、黒と白の境目にまたがるように置いています（`.video-stage`）。

書体は欧文が **Inter**（Google Fonts）。和文は端末標準（iPhone はヒラギノ）に任せています。

### 強調の書き方

- 見出しの中の `<em>` … ティファニーの文字になります（黒い面では明るいティファニー）。斜体にはなりません。
- `.closing-line`（セクションを締める太字の一文）の中の `<em>` と、本文の `<strong>` … 蛍光ペン風のマーカーが引かれます。

```html
<h2>KNCT が合うのは、<br><em>こういう人です。</em></h2>
```

### 改行位置（`.nb`）

`<span class="nb">…</span>` で囲んだ語句は、途中で改行されません。
見出しや中央揃えの文で「ありませ／ん。」のように1〜2文字だけ次の行に落ちるのを防ぐために使っています。
文章を書き換える時は、span ごと消して書き直して構いません（改行位置が少し変わるだけで、崩れはしません）。

### 主なパーツ

| クラス | 見た目 |
|---|---|
| `.badge` | セクションの頭に置く、ティファニーの薄いピルラベル |
| `.badge--solid` | ティファニーで塗ったピル。強調したいとき |
| `.card` | 白いカード。角丸18px・1px枠・薄い影 |
| `.card--hl` | ティファニーの枠と薄い色を足したカード。見せ場用 |
| `.section--alt` | 薄いクリームの帯。1つおきに付けて区切りを見せる |
| `.nb` | 和文を指定位置で折り返すための span |

## 4. 公開するときの注意

- `index.html` に `noindex` を入れてあります。
  予約完了ページが Google の検索結果に出てしまうのを防ぐためなので、**外さないでください。**
- Google Fonts を読み込んでいます（`display=swap` 付き）。
  読み込みが終わるまでは端末の標準フォント（iPhone はヒラギノ）で表示されるので、
  通信が遅い環境でも文字が消えることはありません。
- 実績セクションには「成果には個人差があります」の注記を入れています（景表法対策）。
  金額を載せている以上、消さない方が安全です。

### 公開方法の例

- **Vercel / Netlify** … このリポジトリを繋ぐだけでデプロイされます
- **GitHub Pages** … リポジトリ設定の Pages で公開ブランチを指定します
- レンタルサーバー … 3ファイルをそのまま FTP でアップロードするだけでも動きます

### 独自ドメインを付ける場合

Vercel のプロジェクト設定 → Domains でドメインを追加したあと、`index.html` の
`og:url` と `og:image` の2行を新しいドメインに書き換えてください。
LINE でリンクを送った時のプレビュー画像がこの2行を見ています。

## 5.5 画像の出どころ

| ファイル | 元データ |
|---|---|
| `assets/hero-community.webp` | `toshikinksj-beep/knct-university-lp` の `assets/community.jpg`（1920x1460 / 665KB）を 1600px・WebP に変換（161KB） |
| `assets/p-*.webp` | `Yuuki8255/knct-webinar-slides` の `assets/photos/faces/_切り抜き/*.jpg`（512x512の顔中心トリミング）を 176px・WebP に変換（各5〜8KB） |
| `assets/logo-*.png` | `assets/brand/apple-touch-icon.png` から背景を抜いたもの |

ヒーロー写真は CSS 側（`styles.css` の `.hero::after`）で暗転のグラデーションを
重ねています。写真そのものは加工していないので、明るさを変えたいときは
そのグラデーションの数値を触ってください。

差し替えるときは、元画像を同じファイル名で置くのではなく、
上記の変換（リサイズ + WebP）を通してからにしてください。
元のJPEGのままだとヒーローだけで665KBあり、LINE内ブラウザで重くなります。
